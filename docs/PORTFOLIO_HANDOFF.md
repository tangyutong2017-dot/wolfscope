# WolfScope 作品集交付说明

## 一句话介绍

WolfScope 是一个基于 AgentScope 的九人狼人杀多智能体系统：确定性 Python Engine 掌握规则与上帝信息，九个隔离 Agent 只根据各自 PlayerView 进行发言、推理和结构化行动。

## 作品集推荐文案

第一版狼人杀主要依赖长 Prompt，LLM 经常遗漏信息、混淆他人查验，且一次格式错误就可能中断整局。WolfScope 将问题拆成规则、信息、认知、策略和评测五层：Engine 负责合法状态机；事件路由构造座位隔离视图；公共发言经一次语义提取后进入独立 EvidenceLedger；DecisionBrief 与粗粒度 StrategyBrief 为每次决策提供去重输入；AgentScope 负责结构化模型调用，Runtime 完成 Schema、目标和角色硬约束校验。完整对局以固定 seed 复现，并输出 GOD Replay 与自动评测报告。

## AgentScope 使用说明

- 九个座位拥有隔离的 Runtime 和模型调用记录。
- Pydantic Schema 约束公开发言、投票、夜间技能、警长与死亡技能。
- 模型调用按任务选择 thinking/non-thinking 和 Token 预算。
- Claim 提取与玩家行动拥有独立结构化调用和失败诊断。
- 网络请求有明确超时；格式修复和复杂度降级可审计。

AgentScope 不承担规则裁判：Engine、PlayerView、Evidence、Replay 和全部 M1 测试均可脱离模型运行。这一边界是项目可复现、可测试的关键。

## 诚实披露的限制

8局结项样本中好人仅胜1局，不能证明阵营平衡。当前系统已经解决信息隔离、规则执行和工程稳定性，但好人在不完全信息下形成长期共识仍弱于拥有私有协作计划的狼人。扩大样本与校准好人协同属于后续研究，不影响本次工程版本结项。
