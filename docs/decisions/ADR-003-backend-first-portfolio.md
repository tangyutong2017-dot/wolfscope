# ADR-003：以后端、实验和 README 作为作品集交付

- 状态：Accepted
- 日期：2026-08-06

## 背景

项目的核心问题是认知增强机制是否提升不完全信息博弈表现。Web 前端会增加大量与研究问题无关的开发和维护成本。

## 决策

取消 M4 Web 前端。最终交付为中文 README、架构图、终端 Replay 截图、精选 Replay JSON、M3 实验图表和命令行演示。

## 后果

- 开发资源集中于 Agent 设计、可靠性和实验。
- GitHub 仓库可以完整呈现研究问题和结果。
- 需要高质量终端 Replay 渲染器和报告生成能力。
- 暂不提供在线交互式对局体验。
